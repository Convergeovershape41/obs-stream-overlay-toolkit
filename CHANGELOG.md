## 🚨 Symptoms of the Wrong Overlay Setup

Before you rebuild your scene collection, check whether your stream suffers from any of these classic symptoms. Each one points to a specific fix this guide teaches.

| **Symptom** | **What It Really Means** | **Fix This Guide Teaches** |
|-------------|---------------------------|------------------------------|
| 🧊 Choppy alerts | Heavy animated web sources | Lightweight overlay engine |
| 🕳️ Text unreadable on mobile | Too many layers | Clean composition rules |
| 🐌 OBS high CPU | Bloated browser sources | Local-first alerts |
| 🔀 Scenes out of sync | Manual switching | Scene collections |
| 🎨 Inconsistent branding | No design system | Overlay kit templates |
| 🔇 Audio alerts missing | No mixer routing | Audio routing setup |

> **💡 Tip:** If your OBS CPU spikes on alerts, switch from remote GIFs to local PNG sequences.

## 🚀 First 5 Minutes — Minimal Working Example

This is the smallest overlay setup that looks professional.

**Step 1 — Open OBS.** Any version 28+ works.

**Step 2 — Add a Display Capture.** Capture your game or desktop.

**Step 3 — Add a Browser Source.** Point it at a simple local HTML file.

**Step 4 — Add an Image Source.** Load a transparent PNG frame from the kit.

**Step 5 — Save the scene collection.** Name it "Overlay v1".

> **💡 Tip:** Always create a "Starting Soon" and "Be Right Back" scene from day one — they add a professional feel instantly.

## 🔧 When Things Break

| **Problem** | **Fix** |
|--------------|-----------|
| **Alert doesn't fire** | Check source URL |
| **Overlay blurry** | Match canvas size |
| **High CPU** | Disable animations |
| **Audio clipping** | Reduce mixer gain |
| **Text unreadable** | Bigger font |
| **Cam lag** | Reduce resolution |
